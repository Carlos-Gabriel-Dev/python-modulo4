## 📚 Sobre o projeto

Este repositório reúne exercícios e práticas desenvolvidos durante o estudo do **Módulo 4 de Python**, com foco em Programação Orientada a Objetos (POO).

O objetivo é desenvolver conhecimentos sobre organização de código, reutilização, estruturação de classes e criação de programas mais modulares e eficientes.

Ao longo do projeto, são explorados conceitos fundamentais da programação orientada a objetos por meio de exercícios práticos.

## 🎯 Conteúdos estudados

- **Classes e Objetos:** criação e utilização de estruturas para representar elementos do mundo real.
- **Atributos:** características e propriedades dos objetos.
- **Métodos:** funções definidas dentro das classes.
- **Encapsulamento:** controle de acesso aos dados e métodos.
- **Herança:** reutilização de características e comportamentos entre classes.
- **Polimorfismo:** diferentes implementações para um mesmo comportamento.

## 🚀 Como executar o projeto

**1. Clone o repositório:**

```bash
git clone https://github.com/Carlos-Gabriel-Dev/python-modulo4.git
```

**2. Entre na pasta do projeto:**

```bash
cd python-modulo4
```

**3. Acesse a pasta do exercício desejado:**

```bash
cd ex001
```

**4. Execute o arquivo Python:**

```bash
python nome_do_arquivo.py
```

*Substitua `nome_do_arquivo.py` pelo nome do arquivo do exercício.*
